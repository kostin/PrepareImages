# PrepareImages

Утилита, которая делает из фотографий **готовые карточки для маркетплейса**:
JPEG 762×1100 px, 200 DPI, sRGB IEC61966-2.1, качество 95 %, без метаданных.
Результат складывается в подпапку `edited` рядом с приложением.

Готовые файлы: [Releases](https://github.com/kostin/PrepareImages/releases/latest) ·
[Actions](https://github.com/kostin/PrepareImages/actions) ·
[исходники](https://github.com/kostin/PrepareImages).

Положите `prepare_images` (macOS/Linux) или `prepare_images.exe` (Windows) в папку
с фотографиями и запустите — рядом появится `edited/` с готовыми JPEG.

| Параметр | Значение |
| --- | --- |
| Формат | JPEG, базовый (не progressive) |
| Размер | 762 × 1100 px |
| Разрешение | 200 DPI |
| Цвет | RGB, профиль sRGB IEC61966-2.1 (встроен в файл) |
| Качество | 95, субдискретизация 4:4:4 |
| Метаданные | удалены полностью: EXIF (включая GPS), IPTC, XMP, комментарии |
| Имена | как у исходников, расширение `.jpg` |
| Папка результата | `edited` |

## Что важно знать

- **Кадрирование по центру.** Фото с другими пропорциями заполняет кадр целиком:
  лишнее по краям обрезается, пустых полей нет, изображение не растягивается.
  Поворот по EXIF применяется до обрезки, поэтому фото с телефона не окажется боком.
- **Один файл без зависимостей.** Внутрь упакованы Python, Pillow и профиль sRGB —
  на целевой машине ставить ничего не нужно (ни Python, ни библиотек).
- **Профиль и DPI — не «метаданные».** Они записываются намеренно: это требования
  к результату. Всё личное и служебное (камера, дата, GPS, софт) вычищается.
- **Папка определяется по расположению программы**, а не по текущей папке
  терминала: можно запускать двойным щелчком откуда угодно.
- **Окно не закрывается само.** В конце печатается «Нажмите любую кнопку для
  завершения...» — отчёт и ошибки можно спокойно прочитать и скопировать.
  Для автоматизации есть `--no-pause`.
- **Повторный запуск безопасен.** Результаты перезаписываются, лишних копий не
  появляется. `--clean` дополнительно удаляет из `edited` файлы прошлых прогонов
  (например, если исходники переименовали).
- **Форматы:** JPG, PNG, WEBP, BMP, GIF (первый кадр), TIFF, TGA, ICO, PNM, AVIF.
  Прозрачность заливается белым. Для HEIC с iPhone нужен `pillow-heif`
  (при сборке не включается, чтобы не раздувать файл).

## Запуск

### macOS

```bash
chmod +x prepare_images                  # один раз после скачивания
./prepare_images                         # обработать папку, где лежит файл
```

Finder и Gatekeeper: скачанный файл помечается карантином. Либо правый клик по
файлу → «Открыть», либо один раз снять атрибут:

```bash
xattr -d com.apple.quarantine prepare_images
```

Двойной клик по обычному исполняемому файлу в Finder открывает Терминал и
запускает его — окно останется открытым до нажатия клавиши.

### Windows

Двойной клик по `prepare_images.exe` или из консоли:

```powershell
.\prepare_images.exe
```

### Linux

```bash
chmod +x prepare_images
./prepare_images
```

## Параметры

```
--src ПАПКА        что обрабатывать (по умолчанию — папка приложения)
--out ИМЯ          подпапка результатов (по умолчанию edited)
--size ШxВ         размер, по умолчанию 762x1100
--dpi ЧИСЛО        разрешение, по умолчанию 200
--quality 1..100   качество JPEG, по умолчанию 95
--subsampling 0|1|2  0 = 4:4:4 (по умолчанию), 1 = 4:2:2, 2 = 4:2:0
--clean            удалить прежние картинки из папки результатов
--recursive        обходить вложенные папки (сохраняя структуру)
--no-verify        не перепроверять результат после сохранения
--no-pause         не ждать клавишу в конце (для скриптов и CI)
--profile ПУТЬ     свой ICC-профиль вместо встроенного sRGB
```

Примеры:

```bash
./prepare_images --clean                     # почистить старые результаты и пересобрать
./prepare_images --src ~/Downloads/photos    # обработать другую папку
./prepare_images --size 1000x1500 --dpi 300 --quality 92
```

Каждый файл после сохранения перепроверяется: размер, режим RGB, DPI, профиль,
отсутствие EXIF и лишних JPEG-сегментов. Итог печатается строкой на файл с его
размером, в конце — сводка и общий вес.

## Сборка

Нужен Python 3.10+ и зависимости из `requirements.txt`.

macOS / Linux:

```bash
./tools/build.sh          # dist/prepare_images
python3 tests/smoke_test.py dist/prepare_images
```

Windows:

```powershell
python -m pip install -r requirements.txt
python -m PyInstaller --clean --noconfirm PrepareImages.spec
python tests\smoke_test.py dist\prepare_images.exe
```

CI собирает всё автоматически ([.github/workflows/build.yml](.github/workflows/build.yml)):
Windows x64, macOS Apple Silicon (arm64) и macOS Intel (x64), гоняет smoke-тест на
каждом бинарнике и выкладывает архивы в артефакты. По тегу `v*` создаётся релиз.
