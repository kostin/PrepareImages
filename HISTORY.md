# История

## 2026-11-05 — Первый выпуск: однофайловое приложение для macOS и Windows

**Начало:** 2026-11-05 11:42  
**Завершение:** 2026-11-05 12:20

### Задача
Нужна утилита, которой можно пользоваться без Python и установки библиотек:
положить рядом с фотографиями, запустить — получить готовые JPEG 762x1100
с 200 DPI, профилем sRGB IEC61966-2.1, без метаданных и с качеством 95 %.
Основной пользователь — дизайнер на macOS, где double-click по `.py` открывает
редактор, а ставить Python и Pillow не хочется.

### Сделано
- Ядро `src/prepare_images.py`: crop-to-fill по центру, LANCZOS, поворот по EXIF
  до обрезки, приведение к RGB (прозрачность — на белый), конверсия в sRGB через
  LittleCMS, сохранение без EXIF/IPTC/XMP/комментариев, самопроверка каждого файла.
- Профиль sRGB IEC61966-2.1 (Hewlett-Packard, 3144 байта) встроен в скрипт, чтобы
  результат не зависел от того, какие ICC-профили есть в системе.
- Сборка в один файл через PyInstaller (`PrepareImages.spec`): внутри Python,
  Pillow и профиль; на целевой машине ничего устанавливать не нужно.
- В «замороженном» режиме папка обработки определяется по расположению самого
  бинарника (`sys.executable`), поэтому приложение работает двойным щелчком из
  любой папки.
- В конце окно не закрывается: «Нажмите любую кнопку для завершения...»;
  `--no-pause` для автоматизации.
- CI `.github/workflows/build.yml`: матрица Windows x64 / macOS arm64 / macOS x64,
  smoke-тест на каждом бинарнике, архивы в артефакты, релиз по тегу `v*`.
- Smoke-тест `tests/smoke_test.py` проверяет 762x1100, RGB, 200 DPI, встроенный
  sRGB, отсутствие EXIF и идемпотентность повторного запуска.

### Проверка (локально, Windows)
- Сборка `python -m PyInstaller --clean --noconfirm PrepareImages.spec` → `dist/prepare_images.exe` 14.9 МБ.
- `python tests/smoke_test.py dist/prepare_images.exe` → SMOKE OK.
- Запуск без Python в PATH, из чужой папки, без аргументов: обработана папка
  рядом с бинарником, профиль взят встроенный, EXE не требует установленного Python.
- `bash -n tools/build.sh` — синтаксис без ошибок; в `.sh` и `.yml` только LF.
